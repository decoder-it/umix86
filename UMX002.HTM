Boot

  1. Boot sector reads the 128-sector kernel image to 1000:0000.
  2. Kernel mounts the volumes, loads users, loads UMIX.SYS.
  3. Loads CHAT.SYS (stub) and API.SYS, then runs C:\STARTUP.JCL before the first prompt.
  4. CGA shell on slot 0; serial sessions start on demand.

Tasks and scheduler

13 slots: 0 is the CGA console, 1..10 are serial sessions, 11..12 are program slots. The timer runs a preemptive round-robin; QUANTUM sets 18..1000 Hz (default 18). A task yields with INT 60h AH=7 and exits with AH=8. Critical sections use a byte counter (crit) so the timer skips switching.

Storage

A: floppy, C: hard disk, M: RAM disk. FAT12 or FAT16, 8.3 names, 64 KB file limit. WRITE ON is required before anything writes to C:.

Limits

BASIC lines 61 chars; 16-bit integers; 63-char strings; static web pages 4000 bytes; API request bodies 767 bytes; one running BASIC job at a time.
