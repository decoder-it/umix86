BASIC routes

API ROUTE /api/demo APIHELLO.BAS
curl -s http://HOST:8080/api/demo

Route programs get P$, Q$, M$ and B$; their PRINT output is the response. A busy BASIC session yields 503; a runaway route times out with 500.

Chat

/api/chat, /api/chat/join, /api/chat/send, /api/chat/messages[/N] and DELETE /api/chat/join/<token>. See the chat page.

Limits

One request per connection and web sessions are serialized; request bodies cap at 767 bytes; static files at 4000 bytes. Chat answers 503 when the console ran CHAT OFF or when SLIP/TCP is on. The API is unauthenticated: keep port 8080 on a trusted network.
